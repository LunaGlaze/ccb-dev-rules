# CCB DEV Rules

用於給 [Cataclysm: Cleanwater Bomb](https://github.com/CrimsonCrossBunker/Cataclysm-Cleanwater-Bomb) 使用Agent進行開發的社區貢獻者使用的skill。

# 安裝

```
npx skills add https://github.com/LunaGlaze/ccb-dev-rules
```

# 使用

本skill暫未設置自動觸發，是否能夠自動調用依賴AI自覺。建議在開始會話前使用指令或自然語言要求智能體遵守本skill原則進行開發，例如：

```
/skill:ccb-dev-rules  請幫我我開發一個功能：
```
or
```
請根據 $ccb-dev-rules 技能，幫我進行開發：
```
